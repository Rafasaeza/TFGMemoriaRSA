\section{MQTT Broker Implementation} 
The MQTT broker layer was implemented using Eclipse Mosquitto running in a dedicated Docker container. The broker exposes the standard MQTT port (1883), enabling communication between telemetry producers and future consumers. 

To improve startup reliability, a health check mechanism was configured. The simulator service is only started once the broker is fully operational, preventing connection failures during container initialization.To improve startup reliability, a health check mechanism was configured. The broker container is attached exclusively to the \texttt{mqtt-net} network, ensuring that only components requiring MQTT communication can interact with the service.

\begin{lstlisting}[language=configToml, caption={mosquitto.conf}, label={lst:mosquitto-conf}, basicstyle=\ttfamily\small, breaklines=true]
persistence false
log_dest stdout

listener 1883 0.0.0.0
allow_anonymous true
\end{lstlisting}

\begin{lstlisting}[language=yaml, caption={Mosquitto Docker Compose}, label={lst:mosquitto-docker-compose}, basicstyle=\ttfamily\small, breaklines=true]
services:
  mosquitto:
    image: eclipse-mosquitto:latest
    ports:
      - "1883:1883"
    volumes:
      - ./mosquitto/config:/mosquitto/config
    healthcheck:
      test: ["CMD", "mosquitto_pub", "-h", "localhost", "-p", "1883", "-t", "healthcheck", "-m", "1"]
      interval: 5s
      timeout: 5s
      retries: 10
    networks:
      - mqtt-net
\end{lstlisting}
