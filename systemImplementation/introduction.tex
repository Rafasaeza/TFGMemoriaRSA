\section{Introduction} As discussed in Chapter~\ref{chap:system_architecture}, the proposed solution follows an end-to-end streaming architecture composed of multiple interconnected layers. 

While the previous chapter focused on the architectural design decisions and the rationale behind the selected technologies, this chapter presents the practical implementation of the system. The implementation details of each architectural layer are described, together with the deployment strategy, service integration mechanisms, and the technologies used to establish communication between components. 

Finally, the chapter explains how the different layers are combined to form a complete data pipeline, from telemetry generation at the source systems to data storage and downstream analytics.
